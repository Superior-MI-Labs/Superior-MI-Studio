# Plans (create only for multi-step tasks)

One file per bounded ticket, e.g. `T02-document-session.md`. Keep a concise running contract: goal, current owner, alternatives, chosen boundary, relevant ADR IDs, files, tests, progress, unresolved questions, rollback and final handoff. Do not create one general perpetual mega-plan or use plans as a second decision register; cite and update the canonical ADR when a decision is formally changed.
