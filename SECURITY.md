# Security policy

Superior MI Studio is pre-alpha. No version is currently represented as a supported, security-hardened public release. The application may inspect local project files; only open trusted workspaces and review scripts before executing them.

For potential security vulnerabilities, **do not post exploit details, private files, tokens or credentials in a public issue**. Report privately to **superior.mi.labs@gmail.com**, including the affected version, minimum reproduction and expected impact. We will evaluate and coordinate disclosure; we cannot promise a fixed response time.

Never submit private qualification logs, machine-specific paths or secrets to the public repository without reviewing them first.
